# v0.2.0-beta.1 — experimental public beta

[Česky](v0.2.0-beta.1.cs.md)

Unofficial local Home Assistant integration for the 6-byte Dominus EXA protocol,
using an existing Dominus module and CAR controller. Not the Magis Modbus map.
For technically experienced testers; compatibility evidence is limited to one
installation, not all Immergas boilers or firmware versions.

## Features

- Local telemetry, targets, operating mode, burner modulation and reported activity.
- Explicit CAR/HA ownership, OFF/Summer/Winter, heating-water maximum and DHW target.
- Room-target translation using CAR measurement, not measured-temperature injection.
- Pending DHW targets saved in OFF survive options changes and are applied after
  an explicit Summer/Winter selection. Changing a limit never selects a mode.
- Confirmed new HA choices can be restored after reconnection/restart, including
  known water targets. This can restart heating/DHW. Selecting CAR cancels recovery.
  Foreign sessions, active local CAR, timers, missing permissions and invalid inputs
  block recovery; uncertain writes latch a block across restarts.
- Control permissions default to disabled. Start read-only and commission deliberately.
- English/Czech documentation, MIT license and preserved upstream MIT notice.

## Validation and limitations

96 offline tests passed. Clean HA Core 2026.10.1 on Python 3.14 loaded the integration
through its config flow, 36 entities, the options form/schema and unload. Device
responses were simulated and outbound connections/control commands blocked.
This is not a new physical device or outage-recovery test. See [validation](../validation.md).

Long-term stability, all outage scenarios and independent physical CAR fallback
are not validated. Invalid inputs stop writes, not necessarily the boiler.
HA's persistent TCP connection may prevent simultaneous official-app access.
Antifreeze, cooling, independent DHW-off and service/reset commands are not implemented.
Not a safety interlock, HACS default-catalog listing or HA/Hassfest/HACS certification.

## Installation

Follow [network setup and manual installation](../getting-started.en.md), then
[configuration and safety](../configuration.md). The native dashboard YAML is an
optional generic example; preview images are synthetic illustrations, not a bundled
live dashboard. Never expose Dominus TCP port 2000 to the Internet.

For reports, include model/firmware and HA/integration versions, but no passwords,
MACs, IPs, identification frames or private configuration.
